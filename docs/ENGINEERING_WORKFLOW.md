# Engineering Workflow — System Modeling Starter

## Perfil
Starter para modelagem de sistemas — **base educacional/profissional reutilizável**.

## Padrão
Problema → usuário → requisitos → modelo de domínio → arquitetura → decisões → tarefas → implementação → validação → documentação.

## Loop
**Ler → Compreender → Modelar → Planejar → Implementar → Testar → Revisar → Corrigir → Registrar decisão.**

## Artefatos recomendados
- PRD/escopo
- modelo de domínio
- contratos
- arquitetura
- ADRs/decisões
- regras de implementação
- plano de testes
- segurança quando houver identidade/dados/integrações

## Regra
Não adicionar complexidade sem um caso de uso que a justifique. Toda abstração estrutural deve resolver um problema observável e possuir teste ou exemplo que demonstre seu valor.
