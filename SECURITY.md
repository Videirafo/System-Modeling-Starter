# Security Policy

Este repositório contém apenas documentação, templates e exemplos genéricos de modelagem de sistemas.

Nunca publicar aqui:

- senhas, tokens, chaves privadas ou `.env` reais;
- IPs, endpoints internos ou credenciais de infraestrutura;
- dados de clientes ou requisitos confidenciais;
- dumps de banco, logs com PII ou segredos;
- diagramas que revelem topologia sensível de produção;
- código proprietário de projetos privados.

Se um segredo for publicado por engano, ele deve ser considerado comprometido e revogado/rotacionado imediatamente.
